📘 Grammar note

  • Affirmative (+): He/She/It + verb -s/-es.
  • Negative (−): don’t / doesn’t + base verb.
  • Question (?): Do / Does + subject + base verb?
  • like / love / hate + V-ing: She loves singing.
💡 Translation Tip — Аудармаға кеңес
Келі мен келсап – тары, бидай, т.б. дәнді дақылдарды ұнтақтайтын қатты ағаштан жасалған құрал. Ағылшынша: keli (a hard wooden mortar used to pound grains such as millet and wheat) and kelsap (a wooden pestle used with the keli). Қажет болған жағдайда түсіндірме қосуға болады.
